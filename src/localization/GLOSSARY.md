# Localization Glossary

Source strings live in [`en.json`](en.json). Keep recurring terms consistent with this table.

- Official terms follow the in-game VRChat UI.
- `—` means not yet verified in-game; keep the existing translation.
- Never translate placeholders, CLI flags, URLs, HTML or JSON keys.
- The same English word may need different wording by context; check the JSON path.
